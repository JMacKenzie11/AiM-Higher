# Scorecard

Weekly metrics that answer "is the company healthy". Each metric
has a target and a rolling series of weekly entries.

## Common things people do here

- **Log a week** — the current week's cell accepts a value inline.
  Saved values feed the trend indicator next to each metric.
- **Add a metric** — the inline row at the bottom of the table
  creates one on save.
