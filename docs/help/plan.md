# Plan

The Plan surface is the quarter's game plan: strategic focus areas,
annual goals, and quarterly priorities laid out top-down. Each
priority carries the commitments that will move it forward.

## Common things people do here

- **Open a priority** — click its title to see the priority detail
  page, owner, and the commitments feeding it.
- **Add a priority** — the inline row at the bottom of each list
  saves on submit.
- **Move a priority to the next quarter** — priorities carry
  through with owner and title intact when the quarter closes.

## Heads-up

- Priorities live inside an open quarter. If none is open, you'll
  see an empty state and a link to /quarters to start one.
