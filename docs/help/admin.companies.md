# Companies

System admins see every company on the platform; AiMS Guides see
only the companies they're assigned to coach. Click a company name
to scope into it — the top nav flips to that company's context.

## Common things people do here

- **Open a company** — click its name in the list. From then on
  every module (Dashboard, Plan, Chart, etc.) reads that company's
  data. Use *Exit* in the user menu to drop back out.
- **Create a new company** (system admins only) — the form below
  the list creates the company, seeds its default Visionary/Integrator
  functions, opens the current calendar quarter, and turns on the
  features you pick. Every module (Execution Platform, Strengths,
  Success Tracking, Meeting Facilitation Review, Classroom) is
  available at creation; toggle them later in the company's settings.
  The Industry field is optional at creation and editable afterwards
  from the company's settings page.
- **Manage AiMS Guides** (system admins only) — the Guides card
  invites external coaches, assigns them to companies, and shows
  each guide&rsquo;s current caseload. An aims_guide needs at least
  one company assignment; you can&rsquo;t unassign their last
  company (delete the guide instead).
- **Give a system admin a coaching caseload** (system admins only)
  — a mini-form below the Guides table assigns an existing system
  admin to one or more companies. No invite is sent (they already
  have an account); the assignment shows on the same panel with a
  &ldquo;System admin&rdquo; badge. Removing a sysadmin&rsquo;s
  last assignment is allowed — their access is role-based, not
  assignment-based, so nothing changes about what they can reach.
- **View Guide HQ** (system admins only) — the row-level button on
  each guide opens their Guide HQ read-only. Every mutation
  control (resolve, reschedule, park, reassign) is disabled; jump
  into a company from there to actually act on anything.

## Heads-up

- Guides can&rsquo;t create or archive companies. Those actions
  stay system-admin only.
- The &ldquo;Attention&rdquo; column on the Guides panel currently
  reads &ldquo;—&rdquo; for every row. The per-guide count was
  removed to keep this page fast as caseloads grow; the attention
  queue itself is live on each guide&rsquo;s /hq surface where it
  drives actual behavior.
