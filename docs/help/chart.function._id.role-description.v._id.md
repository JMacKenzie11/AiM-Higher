# Published role description version

A published version of a role description. Nothing on this page can be edited.

## What you can do here

- **Read the version.** The written sections (Position Summary, Strengths & Expertise, Qualifications and Why This Role Matters) read as they did when it was published. The title, outcomes, critical success factors, responsibilities, decision rights and what excellence looks like come from the function as it is now, so they change when the function does. A version written with the *Role Description Creator* reads exactly as it was saved. The top of the page shows who published it and when, and any note they added.
- **Download it.** Where there's a *Download* button, it saves this version as a Word file with the version number in the file name.
- **Go back.** The link at the top left returns to the current role description, where the *Versions* list shows every published version.

To change the role description, go back to the current one.

::: role company_admin,aims_guide,system_admin
## Deleting a version

Delete a version from the *Versions* list on the current role description. It's permanent. Other versions and the current role description aren't affected.
:::

## Common questions

**Why does this look different from the current role description?** The written sections are as they were when this version was published. The current one may have been edited or regenerated since.

**Can I download the current role description instead?** Yes. The current role description has its own *Download* button.
