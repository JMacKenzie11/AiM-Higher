# Free meeting analysis

Run the AiMS meeting analysis on a prospect's leadership meeting and get a branded PDF to review with them and send.

## Start an analysis

1. Enter the person's name, email, company and role.
2. Upload the transcript as a .txt, .vtt or .docx file, or paste it into the box.
3. Select **Analyze Meeting**.

The analysis takes two to four minutes. You land on its page, which updates by itself when it is ready.

## Get the PDF

When the status reads **Ready**, select **Download PDF** to save it, or **Open PDF** to read it in a new tab. The cover says "Prepared for" with their name and company.

The same analysis is on the page under the buttons, so you can read it before your call.

## If it fails

The page shows what went wrong. Select **Run Again** to try once more.

## Past analyses

Every analysis is listed under the form, newest first, with its score and status. Select a name to open it.
