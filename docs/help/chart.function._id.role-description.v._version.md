# Role description — version _n_

A frozen snapshot of the role description as it was published on
this date. Everything on the page is read-only — no edit,
regenerate, or publish. To make a change, go back to the live
role description and either edit the prose sections there or
publish a new version.

## What's frozen

- **Position Summary, Why This Role Matters** are the exact text
  from when this version was published — including any manual
  overrides live at that time.
- **Chart-driven sections** (Success Measures, Key
  Responsibilities, Decision Rights, Competency Indicators) also
  reflect the state at publish time. The chart can change under
  them without affecting this snapshot.
- **The .docx download** on this version returns the same frozen
  content — safe to hand to a candidate or archive.

## Common things people do here

- **Download .docx** — pulls this specific version as a Word
  file. The filename includes the version number so archived
  copies stay distinguishable.
- **Back to role description** — top-left crumb returns to the
  live view. The Versions section there lists every published
  version if you want to browse others.

## Access

Anyone on the company can view any published version. Deleting a
version is admin-only and happens from the Versions list on the
live role description page.
