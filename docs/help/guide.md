# Aimee's meeting invitations

Aimee used to invite one person at each company, its AiMS champion, to talk each leadership meeting through. She doesn't send these invitations any more, and there's no AiMS champion now.

## What you can do here

- **Open a chat you already started.** If you clicked *Talk it through* on an earlier invitation, that link still opens the same chat. You'll also find it in your Ask Aimee list.
- **Debrief a meeting yourself.** Company admins and coaches can start *Debrief a meeting* on Ask Aimee whenever they like.

## Common questions

**I clicked an old invitation and it says Aimee no longer sends these.** That invitation was never opened, so there's nothing to go back to. Read the meeting on **Meeting Summaries**, or start *Debrief a meeting* on Ask Aimee if you can see it.
